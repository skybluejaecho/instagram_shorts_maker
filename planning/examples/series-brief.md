# 시리즈 기획·인수인계 양식

이 양식을 `local/series/<시리즈 ID>/BRIEF.md`에 복사해 작성한다. 공유할 문서는 Git 관리 위치에 둘 수도 있다. 자동 요약 명령은 이 문서를 덮어쓰지 않는다. 이 파일 자체가 생성 모델에 자동 전달되는 것은 아니다.

- 마지막 수정일:
- 등록 설정 파일(저장소 상대경로):
- 공통 또는 전용 제작 어댑터:
- 대상 시청자 / 사전 지식:
- 시청자에게 전달할 가치:

## 콘텐츠 범위

- 다룰 주제 / 다루지 않을 주제:
- 회차별 학습 목표와 중복 판단 기준:
- 말투·용어·설명 깊이:
- 사실 근거 파일과 출처·확인일:
- 근거가 충분하지 않을 때의 처리:

사실 근거는 UTF-8 `.md`/`.txt`로 준비하고 `contentReview.sources`에 등록한다. 현재 제한은 20개, 파일당 128 KiB, 전체 512 KiB다. 긴 원본을 임의로 잘라 등록하지 말고 사용할 범위·선별 이유·원문 위치를 함께 기록한다. Drive 자료도 저장소 안의 같은 상대경로로 복원한다.

## 확정한 제작 규칙

- 길이 / 현재 지원 출력(1080×1920·30fps):
- 음성 이름·속도 / 실제 설정 위치:
- 색상·글꼴 / 실제 설정 위치:
- 장면 종류·순서·화면 밀도·전환·강조:
- 음성 큐에 연결할 애니메이션 기준:
- 내용·화면·기술 검수 기준:
- 아직 구현되지 않은 요구사항:

지원되는 규칙은 `series.json`의 실제 허용 필드, 회차 JSON 또는 어댑터 코드에 연결한다. 이 문서의 자유 형식 항목을 그대로 시리즈 JSON에 추가하면 사전 점검에서 거부될 수 있다.
